# Launcher assets

`boxart_sm64ds_eu.tga` is the European Nintendo DS front-cover scan used by
the native recomp-ui launcher. It was retrieved on 2026-07-31 from the
[LaunchBox Games Database](https://gamesdb.launchbox-app.com/games/images/6594-super-mario-64-ds)
(“Box - Front (Europe)”). Super Mario 64 DS artwork and trademarks are owned
by Nintendo.
