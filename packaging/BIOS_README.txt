Super Mario 64 DS Recomp requires BIOS and firmware dumped from your own
Nintendo DS hardware.

Place these files in this bios folder before launching:

  biosnds9.rom
    size: 4096 bytes
    sha1: bfaac75f101c135e32e2aaf541de6b1be4c8c62d

  biosnds7.rom
    size: 16384 bytes
    sha1: 24f67bdea115a2c847c8813a262502ee1607b7df

  firmware.bin
    size: 262144 bytes
    sha1: ae22de59fbf3f35ccfbeacaeba6fa87ac5e7b14b

The release package intentionally does not include Nintendo BIOS, firmware,
ROM, save data, generated code, or captured game data.
